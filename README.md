# Dummy Text & Image Generator for TYPO3 CMS

Adds an "insert dummy text" button next to backend form fields and an
"add dummy image" button to file fields. One click fills the field with lorem
ipsum (or attaches a generated image) — designed so the sources can later be
swapped for AI generated content.

A modern re-implementation of the classic
[`lorem_ipsum`](https://extensions.typo3.org/extension/lorem_ipsum) extension
by Kasper Skårhøj for TYPO3 v13/v14.
